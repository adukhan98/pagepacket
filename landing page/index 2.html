01 — How it works

You're not the only one
editing your files.

Codex, Claude Code, Cursor, shell scripts — they all touch the same workspace. pagepacket makes every external edit visible, reviewable, and reversible.

01

Write in plain Markdown

Open any folder as a workspace. Edit .md files with syntax highlighting, live preview, and split mode. Your files stay portable — Git, shell tools, and other editors all work unchanged.

02

Agents edit on disk

When an agent changes a file, pagepacket detects it and captures the proposed version as a review packet. Your draft is never silently overwritten — the human's text always survives.

03

Accept or reject

Review agent edits as block-level diffs. Accept the good stuff, reject what doesn't fit. Conflicts surface clearly — your draft stays visible beside the agent's proposal at all times.

02 — Features

A native editor that won't lock you in.

pagepacket gives you the comfort of a native Mac Markdown editor and the safety of reviewable agent edits — without databases, cloud accounts, or proprietary formats.

Inline diff review

Agent edits appear as block-level diffs right in the editor. Accept or reject individual hunks without leaving your writing flow. Conflicts surface clearly — your draft stays visible beside the agent's proposal.

Conflict resolution

When human and agent edits touch the same range, pagepacket keeps your text by default and flags the conflict. An explicit split view shows your draft beside the agent's proposal — nothing gets silently merged.

Version snapshots

Every save creates a local snapshot in .pagepacket/history/. Roll back to any prior version — no Git required. Snapshots are plain files on disk, so you can diff, grep, or back them up however you like.

Folder-based workspaces

Open any folder as a workspace. pagepacket reads .md files natively — no import, no database, no lock-in. Your folder structure is the workspace structure. Close the app, everything's still there.

File-change detection

pagepacket watches your workspace for external changes. When an agent or shell script modifies a file, you see it immediately — proposed edits surface as review packets, not silent overwrites.

Local image import

Drop images into your vault and pagepacket copies them to an assets/ folder with relative Markdown links. Your images travel with your files — no broken references, no cloud uploads.

04 — CLI

Scriptable from the terminal.

The pagepacket-cli tool lets agents and shell scripts interact with your workspace programmatically — check status, create snapshots, apply checkpoints, and browse history.

terminal — pagepacket-cli
$ pagepacket-cli status SampleVault
→ Workspace: SampleVault
→ Files: 12 markdown, 4 images
→ Pending agent edits: 2
✓ welcome.md — ready for review
⚠ notes.md — 1 conflict detected
$ pagepacket-cli snapshot SampleVault welcome.md \
--message "Before agent edits"
✓ Checkpoint saved to .pagepacket/history/
$ pagepacket-cli apply SampleVault welcome.md \
--author codex --summary "Tighten intro paragraph"
→ Proposed change:
⚠ 1 conflict on line 5 — your edit vs agent edit
→ Opening review packet...
$ pagepacket-cli history SampleVault welcome.md
2024-06-28 14:22 a3f2c1 "Before agent edits"
2024-06-28 14:18 7b8e0d "Draft intro rewrite"
2024-06-28 14:01 f1c9a4 "Initial welcome page"
