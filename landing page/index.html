What a packet contains.

A packet is not a chat transcript and not a black-box merge. It is a local, inspectable bundle of file changes, conflicts, and checkpoints.

A

Block-level diff

Changed Markdown is shown as readable hunks, not a wall of raw patch text.

B

Conflict context

Your draft and the agent proposal remain visible when both touch the same range.

C

Local history

Snapshots live in the workspace sidecar, so rollback does not require a cloud account.

D

Portable files

The Markdown file is still a Markdown file. pagepacket adds review context around it.

Scriptable when agents need a handle.

`pagepacket-cli` gives local tools a narrow way to inspect status, save checkpoints, and open a review packet without pretending to own the editor. 

$ pagepacket-cli status SampleVault
workspace: SampleVault
markdown: 12 files
agent edits: pending
conflicts: review required

$ pagepacket-cli snapshot SampleVault welcome.md \
  --message "Before agent edits"
saved: .pagepacket/history/welcome.md
