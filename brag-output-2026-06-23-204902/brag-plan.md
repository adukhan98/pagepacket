# Brag Plan: Graft

## What is this app?

Graft is a local macOS Markdown editor where humans write plain files and external agents submit reviewable edits before they land.

## The angle

Agent editing should feel dangerous until the change is visible. The video turns that fear into a hand-drawn paper riot: a Markdown file gets attacked by agent edits, Graft stamps order onto the mess, and the human stays in control.

## Hook (first 2-3 seconds)

Start with a giant hand-written warning: "YOUR AGENT CHANGED YOUR MARKDOWN." A raw Markdown sheet jitters underneath like a ransom-note desk.

## Key moments (the middle)

- An external agent edit slams into a Markdown document as a hot-pink patch strip.
- Graft turns the chaos into a review packet with ACCEPT / REJECT controls.
- A conflict stamp lands, then a checkpoint tape locks the draft before changes apply.

## Outro / punchline

Graft lands as the tool that makes agent-written Markdown reviewable: "WRITE WITH AGENTS. KEEP THE DRAFT."

## User flow worth showing

Open a Markdown file -> agent edits the same file -> Graft captures the change as a review packet -> user accepts/rejects and checkpoints before landing the edit.

## Tone

- Preset: chaotic
- Creative direction: neobrutalist hand-drawn handwritten paper riot
- Interpretation: fast cuts, giant marker typography, torn paper, sharp black borders, hot-pink and acid-green stamps, jitter, scribbles, and loud beat-synced motion while keeping each major line readable.

## Format: landscape - 1920x1080

## Duration: 24 seconds

## Visual identity (from the project)

- Background: warm paper `#fff2c7`
- Accent: hot pink `#ff4d8b`, acid green `#9cff3d`, deep teal `#123c3c`
- Text: ink `#0a0a0a`
- Display font: Bangers / Impact fallback
- Handwritten font: Permanent Marker / marker fallback
- Mono font: Space Mono / monospace fallback
- Strongest visual element: hand-built Graft review UI with real product language: plain Markdown, agent edit, review packet, conflict, checkpoint.

## Audio direction

- Role: dense chaotic launch bed
- Music: `happy-beats-business-moves-vol-10-by-ende-dot-app.mp3`
- Music treatment: start immediately at medium volume, let impacts punch through, hard final hit.
- Music cue guidance: bundled cue preset copied; use beat grid from 0.27s onward and strong cues near 18.55s, 20.19s, 20.74s, and 22.92s for final payoff.
- Audio treatment: timed visual hits with a loudness-normalized music/SFX mix. No live audio-reactive visuals in this pass.
- SFX posture: dense but intentional; impacts, glitches, card shoves, clicks, and one final bell.
- Audio-coupled moments: warning slam, agent patch impact, review packet reveal, accept/reject controls, checkpoint stamp, final logo hit.
- Restraint rule: do not obscure readability; text lands hard, then holds.
