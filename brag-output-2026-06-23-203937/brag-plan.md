# Brag Plan: Graft

## What is this app?

Graft is a premium local Markdown editor for macOS where humans write plain files and external agents submit reviewable edits before they land.

## The angle

Graft is not another collaborative document app. It is a local source-of-truth editor for the new loop: human writing, agent edits, visible review, and recoverable checkpoints in the same folder.

## Hook (first 2-3 seconds)

Open on warm paper-source material with Markdown marks and a green graft seam. The first readable line is: "Markdown is the source."

## Key moments (the middle)

- Agent traces enter the same local Markdown workspace instead of moving work into another silo.
- Human and agent edits join through visible review before they land.
- Snapshots, comparisons, and restores create a local trail without changing the plain-file promise.

## Outro / punchline

Land on the Graft app icon and the promise: "The Markdown editor for you and your agents." Supporting line: "Coming soon for macOS."

## User flow worth showing

Open a Markdown workspace -> an external agent edits the same files -> Graft turns the change into reviewable inline work -> the user can checkpoint, compare, and restore.

## Tone

- Preset: polished
- Creative direction: quiet premium product film with cinematic source-material macro movement
- Interpretation: restrained pacing, warm light canvas, readable editorial type, no generic AI sparkle language, and motion that feels crafted rather than loud.
